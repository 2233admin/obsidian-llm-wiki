# Project Hub recovery-loop tasks

## Delivery contract

`tasks.md` tracks reviewable work packages. The executable step-by-step plan is
`docs/superpowers/plans/2026-08-27-project-hub-recovery-loop.md`; its verified
source baseline and file map are part of the Phase 0 gate. Every implementation
task is one working day or less, changes only the reviewed files, adds observable
tests, and ends with evidence in the owning Work-OS issue. Luna receives one
reviewed task at a time only after dependencies pass. If the source baseline,
listed file, caller set, or contract conflicts with the approved snapshot, Luna
stops and escalates; it does not add a shim, choose another path, or widen scope.
