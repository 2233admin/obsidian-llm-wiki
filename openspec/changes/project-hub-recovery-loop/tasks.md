# Project Hub recovery-loop tasks

## Delivery contract

Every implementation task is one working day or less, changes only the named files, adds its named observable tests, and ends with evidence in the owning Work-OS issue. Luna receives one reviewed task at a time only after dependencies pass. If a listed file or contract conflicts with the approved snapshot, Luna stops and escalates; it does not add a shim, choose another path, or widen scope.
